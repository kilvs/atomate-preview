# Self-hosted fonts

The same files as Omble (client, 17 Sep 2026: "As for the font, use the same as Omble").

- `plus-jakarta-sans-latin-var.woff2`: Plus Jakarta Sans, variable 600–700, headings and every emphasised word.
- `inter-latin-var.woff2`: Inter, variable 400–700, everything else.

Both are latin-subset variable fonts under the SIL Open Font License 1.1, which allows self-hosting.
Library copies: `~/Documents/Fonts/{Inter,Plus Jakarta Sans}/Latin subset/`.
The earlier Gilroy Bold and Galano Regular files are in `Guide & References/Unused site assets (moved 17 Sep 2026)/`.
