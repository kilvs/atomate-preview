## Resolved contradictions (V2 wins)

- "Send the way your clients prefer": icon cards under the split section. Not ADmyBRAND template.
- Logo marquee ("works with tools you're already using"): dropped — redundant with the tabbed integrations section (Dext-style, no icons, static logos per tab).

## Inspo — keep / drop

Keep as intent: Merge hero restraint; Brex cards with real UI previews; without/with comparison table (content is strong, current mock is a spreadsheet — redesign opportunity); Karbon quote + UI pairing; Dext tabs; Flowbase click-to-reveal steps.

Drop: Xero blob illustration (blobs banned); ADmyBRAND template (generic AI-SaaS); Dribbble CTA with isometric diamonds (decorative, purple); Ignition teal blobs.

## Omble relationship (recommendation, awaiting client confirmation)

Several V2 references are Omble sections (trust bar, lodgments/obligations, comparison table, 3-card insights). Treat ATOmate and Omble as a BAW family: share skeleton (Client-First structure, spacing rhythm, component grammar, Webflow instructions kit, CLAUDE.md conventions); differentiate on palette (blue/navy-led, orange scarce accent — Omble is orange-led), typography (Gilroy/Galano vs Inter/Plus Jakarta), and the arrow diagonal as ATOmate's structural motif. Confirm the client is comfortable with visible sibling resemblance.

## Arrow motif (position)

The arrow in the logo is the only ownable brand element; palette alone is default fintech. Use the arrow structurally (the logo's ~30° diagonal as system geometry, one deliberate motion moment), not as ambient animated background behind a restrained hero.
